# BiLSTM Speech Enhancement (Phase-Sensitive Masking)

Single-channel speech denoising with a Bidirectional LSTM that predicts a
time-frequency **soft mask** over a hand-written STFT front end, trained and
benchmarked on **VoiceBank-DEMAND**, with a classical **spectral-subtraction**
baseline for comparison.

> **Origin & scope.** The core pipeline (custom STFT/ISTFT, BiLSTM mask model,
> PSM target, reconstruction) was built as a 2-person course project for
> *Advanced Topics in Speech Processing* at IIT Kharagpur
> (Shaik Asim Shareef, Dasari Pardha Saradhi). That version trained on ~100 of
> 11 572 files because the data loader held every framed spectrogram in RAM.
> This repo is a follow-up rebuild: a **streaming data pipeline**, **full-corpus
> training on GPU**, and a **reproducible evaluation** against the noisy input
> and the classical baseline on the official 824-file test set. See
> [`docs/REPORT.md`](docs/REPORT.md).

## Method

```
noisy.wav
  -> pre-emphasis   y[n] = x[n] - 0.97 x[n-1]        (flatten spectral tilt)
  -> STFT           512-pt FFT, 128 hop, Hann        (custom, src/manual_stft.py)
  -> frame          32 frames (~256 ms), stride 8    -> [N, 32, 257]
  -> BiLSTM(128) -> BiLSTM(64) -> TimeDistributed(Dense 257, sigmoid)  -> mask
  -> spectral floor max(mask, 0.05)  x |Y|           (anti musical-noise)
  -> ISTFT with noisy phase  -> de-emphasis  -> enhanced.wav
```

- **Target: Phase-Sensitive Mask** `PSM = (|S|/|Y|) * cos(theta_S - theta_Y)`,
  clipped to `[0, 1]`. The cosine term down-weights bins whose phase the noise
  has corrupted, which a magnitude-only Ideal Ratio Mask ignores.
  (`MASK_TYPE = "irm"` in `src/config.py` switches back to the plain IRM.)
- **From-scratch STFT/ISTFT** (`src/manual_stft.py`): explicit framing, Hann
  windowing, conjugate-symmetric spectrum (257 = 512/2 + 1 bins), and
  window-sum-normalised overlap-add. No `librosa.stft` in the model path.
- **Streaming dataset** (`src/dataset.py`): a `tf.keras.utils.Sequence` that
  reads only file headers to index windows, then loads/transforms one
  utterance at a time. RAM is flat at a few hundred MB for the full 11 572-file
  corpus (the original eager loader needed ~120 GB and capped at ~100 files).


## Quickstart

```bash
pip install -r requirements.txt
# dataset -> speech/{clean,noisy}_{train,test}set_wav/   (scripts/prepare_dataset.md)

python src/dataset.py                       # index + time one batch
python src/train.py --epochs 40 --batch 128 # GPU strongly recommended
python src/evaluate.py                      # writes results/metrics.md
python src/inference.py --noisy n.wav --clean c.wav
```

GPU training: open `notebooks/train_colab.ipynb` in Google Colab (T4).
Trained weights are attached to the GitHub Release, not committed.

## Limitations

- Magnitude mask only; phase is reused from the noisy signal (Griffin-Lim-style
  approximation). No complex-domain or diffusion phase estimation.
- Trained/tested on VoiceBank-DEMAND; not validated on unseen noise types or
  languages.
- On already-clean input the mask still attenuates slightly ("do no harm"
  limitation) - see `docs/REPORT.md`.
